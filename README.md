# hlpatch-readall-spec

`libhachimi_ura.so` 的「全格式可读」改造规格书。

**目标**：插件面对任何输入——内存、文件、SQLite、msgpack、压缩包、UTF-8 / UTF-16 / 二进制——都能安全读出，输出永远是合法 JSON，不乱码、不截断、不崩。

> 本仓只放规格与流程，不放实现代码。

## 一页看懂

```
P0 冻结基线  →  P1 编码基座  →  P2 安全读取  →  P3 通用解码  →  P4 端点注册  →  P5 输出契约  →  P6 构建验收
                  ↑ 不先做这个            ↑ 不先做这个
                    后面全部要返工          后面全部会崩
```

## 三条铁律

| # | 规则 |
|:-:|:--|
| 1 | 指针**不跨请求缓存**——对象图每帧重建 |
| 2 | **禁止**全量 classes / 全量 dump——曾把游戏打崩 |
| 3 | 装机必须在游戏**静止**时——运行中打补丁 = 无声 SIGSEGV |

## 两次最容易翻车的地方

| 问题 | 正确做法 |
|:--|:--|
| 日文乱码 | URL 解码必须是 `%XX → 字节 → + → UTF-8`，不能逐字节 `as char` |
| 端点"不存在" | 新端点必须在 **4 处**登记：路由 / `DL_ALLOWED` / `/health` / `not_found` |

## 端口

**不动。** 全部端点挂 `127.0.0.1:18765` 的新 path 下，不新开监听端口。
